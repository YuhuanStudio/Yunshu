Benchmarks

Performance on Apple Silicon — populated by just bench-* commands or scripts/benchmark_paper.py.

Methodology

All benchmarks follow a consistent methodology to ensure fair comparison:

  • Same quantization: All models use 4-bit quantization (MLX format) unless noted
  • Same model weights: Identical checkpoints across framework runs
  • Same hardware: Single Apple Silicon Mac (results are device-specific)
  • Same software: Yunshu engine, MLX framework, same Python/MLX versions
  • Warm cache: One warmup generation before measurement
  • Single request: Batch size = 1 for all measurements

Metrics:

  • TTFT — Time To First Token (ms) from request to first output token
  • Throughput — Decode tokens/second during generation phase
  • E2E Latency — End-to-end latency (ms) for a fixed-length generation
  • Peak Memory — Maximum GPU memory (GB) during generation
  • Baseline Memory — GPU memory (GB) after model load (idle)
  • Accuracy — Benchmark-specific accuracy where applicable (e.g., WER for ASR)
