This index lists every shipped feature by area. Each row names the feature, what it does, its status and where the docs cover it. The list is generated from the repository feature index (`docs/feature_index.json`), which a test keeps in step with the documentation.

| Status | Meaning |
|---|---|
| Stable | Works as described and is covered by tests or gates |
| Partial | Works for the scope named in the summary; the rest is not implemented or not verified |
| Experimental | Behind an experimental setting; may change or be removed |
