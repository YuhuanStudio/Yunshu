本索引依领域列出所有已提供的功能。每一列标示功能名称、用途、状态，以及文档中涵盖它的页面。清单由保存库的功能索引（`docs/feature_index.json`）产生，并由测试确保与文档保持一致。

| 状态 | 意义 |
|---|---|
| 稳定 | 如描述运作，并有测试或闸门涵盖 |
| 部分支持 | 在摘要所述范围内可用；其余尚未实现或尚未验证 |
| 实验性 | 受实验性配置控制；可能变更或移除 |

## 推论

| 功能 | 说明 | 状态 | 文档 |
|---|---|---|---|
| 无损推测解码 | DFlash2、MTP 与 prompt 拷贝式草稿，搭配 batch-invariant kernel；贪婪输出与关闭推测时相同 | 稳定 | [推测解码](/docs/internals/speculative-decoding) |
| 文本模型推测 | 针对 mlx-lm 模型的 n-gram / suffix 与 Gemma 4 assistant 草稿（外部 draft 模型是另一个输出不相同的选项） | 稳定 | [推测解码](/docs/internals/speculative-decoding), [选项](/docs/guides/options) |
| 前缀缓存（APC） | 位于 RAM、SSD 与选用保存层的精确混合 checkpoint；含图像与音频键值 | 稳定 | [前缀缓存内部机制](/docs/internals/prefix-cache), [Prompt 缓存](/docs/guides/prompt-caching) |
| 结构化输出 | 在解码期间强制 JSON schema、regex、选项与 grammar，包含工具参数 | 稳定 | [结构化输出](/docs/guides/structured-output), [受限解码内部机制](/docs/internals/constrained-decoding) |
| 有损内存选项 | int8 KV、压缩的 WARM 层与加载时量化；默认关闭 | 稳定 | [选项](/docs/guides/options), [内存管理](/docs/internals/memory), [配置](/docs/guides/configuration) |
| 大型 MoE 加载（部分支持） | 从张量形状推导社群版 DeepSeek-V4-Flash 的比特数与 group size；加载前先做容量检查 | 部分支持 | [模型支持](/docs/guides/model-support) |
| Round driver（实验性） | 针对 dense Qwen3.5 系列模型、Yunshu 自有的推测 round driver | 实验性 | [Round driver](/docs/developers/round-driver) |
| 模型支持 | 依系列说明哪些已调校、哪些走通用路径、哪些已验证 | 稳定 | [模型支持](/docs/guides/model-support) |
| 下一回合预演 | 符合条件的文本回复之后，以标准 stride 做 APC 预演；boundary/exact 是会改变量值、需明确选用的选项 | 稳定 | [Prefill 与预演](/docs/internals/prefill-and-rehearsal) |
| Batch 转 lane 升级 | 共用 batch 缩减到一个 row 时，符合条件的贪婪请求会移到推测 lane；多 row 推测尚未实现 | 稳定 | [推测解码](/docs/internals/speculative-decoding) |
