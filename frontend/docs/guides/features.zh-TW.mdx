本索引依領域列出所有已提供的功能。每一列標示功能名稱、用途、狀態，以及文件中涵蓋它的頁面。清單由儲存庫的功能索引（`docs/feature_index.json`）產生，並由測試確保與文件保持一致。

| 狀態 | 意義 |
|---|---|
| 穩定 | 如描述運作，並有測試或閘門涵蓋 |
| 部分支援 | 在摘要所述範圍內可用；其餘尚未實作或尚未驗證 |
| 實驗性 | 受實驗性設定控制；可能變更或移除 |

## 推論

| 功能 | 說明 | 狀態 | 文件 |
|---|---|---|---|
| 無損推測解碼 | DFlash2、MTP 與 prompt 複製式草稿，搭配 batch-invariant kernel；貪婪輸出與關閉推測時相同 | 穩定 | [推測解碼](/docs/internals/speculative-decoding) |
| 文字模型推測 | 針對 mlx-lm 模型的 n-gram / suffix 與 Gemma 4 assistant 草稿（外部 draft 模型是另一個輸出不相同的選項） | 穩定 | [推測解碼](/docs/internals/speculative-decoding), [選項](/docs/guides/options) |
| 前綴快取（APC） | 位於 RAM、SSD 與選用儲存層的精確混合 checkpoint；含影像與音訊鍵值 | 穩定 | [前綴快取內部機制](/docs/internals/prefix-cache), [Prompt 快取](/docs/guides/prompt-caching) |
| 結構化輸出 | 在解碼期間強制 JSON schema、regex、選項與 grammar，包含工具參數 | 穩定 | [結構化輸出](/docs/guides/structured-output), [受限解碼內部機制](/docs/internals/constrained-decoding) |
| 有損記憶體選項 | int8 KV、壓縮的 WARM 層與載入時量化；預設關閉 | 穩定 | [選項](/docs/guides/options), [記憶體管理](/docs/internals/memory), [設定](/docs/guides/configuration) |
| 大型 MoE 載入（部分支援） | 從張量形狀推導社群版 DeepSeek-V4-Flash 的位元數與 group size；載入前先做容量檢查 | 部分支援 | [模型支援](/docs/guides/model-support) |
| Round driver（實驗性） | 針對 dense Qwen3.5 系列模型、Yunshu 自有的推測 round driver | 實驗性 | [Round driver](/docs/developers/round-driver) |
| 模型支援 | 依系列說明哪些已調校、哪些走通用路徑、哪些已驗證 | 穩定 | [模型支援](/docs/guides/model-support) |
| 下一回合預演 | 符合條件的文字回覆之後，以標準 stride 做 APC 預演；boundary/exact 是會改變數值、需明確選用的選項 | 穩定 | [Prefill 與預演](/docs/internals/prefill-and-rehearsal) |
| Batch 轉 lane 升級 | 共用 batch 縮減到一個 row 時，符合條件的貪婪請求會移到推測 lane；多 row 推測尚未實作 | 穩定 | [推測解碼](/docs/internals/speculative-decoding) |
