本页涵盖两组路由。图像路由遵循 OpenAI 的 `/v1/images/*` 规格，运行本地的 Z-Image 类扩散管线。`POST /v1/ocr` 是 Yunshu 自己的路由（不属于 OpenAI API），会用 OCR 模型或任何已加载的视觉语言模型把上传的图片转成文本。

</Callout>

## 图像生成

`POST /v1/images/generations` 接收 JSON 正文。

| 参数 | 类型 | 必填 | 说明 | 状态 |
| --- | --- | --- | --- | --- |
| `prompt` | string | 是 | 提示词，不可为空白。 | 支持 |
| `model` | string | 否 | 图像模型 id，默认 `Z-Image-Turbo-MLX-4bit`。若与已加载的图像模型都不相符、但刚好只加载了一个图像模型，就使用那一个。 | 支持 |
| `n` | integer | 否 | 1 到 10，默认 1。图片依序逐张生成。 | 支持 |
| `size` | string | 否 | `WIDTHxHEIGHT`，默认 `1024x1024`。两边都必须介于 64 到 2048，且为 64 的倍数。 | 支持 |
| `response_format` | string | 否 | `b64_json`（默认）或 `url`。 | 支持 |
| `num_inference_steps` | integer | 否 | 1 到 100，默认 4（针对 Turbo 模型调整）。 | 扩展 |
| `seed` | integer | 否 | 第 `i` 张使用 `seed + i`。未提供 seed 时，每张图各自使用新的随机 seed。 | 扩展 |
| `control_image` | string | 否 | 作为控制信号的 base64 图片（可带 `data:` URL 前缀）。 | 扩展 |
| `control_scale` | number | 否 | 0 到 2，默认 0.8。仅在有 `control_image` 时使用。 | 扩展 |
| `preview_interval` | integer | 否 | 仅流式路由：每 N 步输出一张解码后的预览（0 表示关闭）。 | 扩展 |
| `quality`、`style`、`background`、`output_format`、`moderation` | | 否 | 不在结构内的 OpenAI 字段，会被忽略。 | 接受但忽略 |

响应一律是 PNG 数据：

```json
{
  "created": 1767225600,
  "data": [
    { "b64_json": "iVBORw0KGgo..." }
  ]
}
```

使用 `response_format: "url"` 时，每个项目的 `url` 是 `data:image/png;base64,...` URI（同时带有 `b64_json`）。Yunshu 不代管生成的文件，所以 `url` 不会是 http 链接。

### 流式生成

`POST /v1/images/generations/stream` 使用相同的正文，返回 `text/event-stream`。每个事件是一行带 JSON 对象的 `data:`，没有 `event:` 名称：

| 事件形式 | 意义 |
| --- | --- |
| `{"step", "total_steps", "progress", "is_final": false}` | 去噪进度。 |
| `{"step", "total_steps", "progress", "image", "is_final": false, "is_preview": true}` | 附带 base64 PNG 预览的进度（仅当 `preview_interval` 大于 0）。 |
| `{"step", "progress": 1.0, "image", "is_final": true}` | base64 PNG 的最终图片，之后接 `data: [DONE]`。 |
| `{"type": "cancelled"}` | 请求被取消（例如通过 `POST /v1/cancel`），之后接 `[DONE]`。 |
| `{"error": {"message", "type"}}` | 流式开始后发生失败，之后接 `[DONE]`。 |

流式路由只生成一张图片，不使用 `n` 与 `control_image`。

## 编辑与变体

`POST /v1/images/edits` 与 `POST /v1/images/variations` 可以接收 `multipart/form-data`（OpenAI SDK 的送法：`image` 文件加文本字段），也可以接收含 base64 `image` 的 JSON。只会读取第一个 `image` 文件；`mask` 与其他文件会被忽略。图片超过 25 MB 会返回 `413`。

| 参数 | 类型 | 必填 | 说明 | 状态 |
| --- | --- | --- | --- | --- |
| `image` | file 或 base64 string | 是 | 来源图片。 | 支持 |
| `prompt` | string | 编辑：是 | 编辑指示。变体没有 `prompt` 字段（传了也会被忽略）。 | 支持 |
| `model` | string | 否 | 同图像生成。 | 支持 |
| `n` | integer | 否 | 1 到 10，默认 1。 | 支持 |
| `size` | string | 否 | 同图像生成。 | 支持 |
| `response_format` | string | 否 | `b64_json`（默认）或 `url`（data URI，不含 `b64_json`）。 | 支持 |
| `num_inference_steps`、`seed` | | 否 | 同图像生成。 | 扩展 |
| `denoise_strength` | number | 否 | 0 到 1。决定结果可偏离来源图多远：编辑默认 0.8，变体默认 0.45。 | 扩展 |
| `mask` | file | 否 | 局部重绘遮罩。 | 接受但忽略 |

编辑是图生图：以来源图片为起点，由 `denoise_strength` 决定结果可以偏离来源多少。这两个路由没有以遮罩为基础的局部重绘。

## OCR

`POST /v1/ocr` 使用 `multipart/form-data`。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | file | 是 | 图片，最大 10 MB。可读取 PNG、JPEG、WebP、TIFF、BMP；文件会以 Pillow 验证，不是图片时返回 `400`。 |
| `model` | string | 否 | OCR 或 VLM 模型 id。留空表示使用第一个已加载的 OCR 引擎。 |
| `task` | string | 否 | `text`（默认）、`formula` 或 `table`。 |
| `language` | string | 否 | 引导输出语言的提示。不会做语言侦测。 |

引擎选择：优先使用已加载的 OCR 类模型（例如 GLM-OCR checkpoint）。没有的话，会退而使用已加载的视觉语言模型，搭配文本辨识提示词。两者都没有时，服务器返回 `503`。

```json
{
  "text": "Invoice 2026-001\nTotal: 120.00",
  "model": "mlx-community/GLM-OCR-bf16",
  "confidence": 0.0,
  "language": null,
  "task": "text",
  "prompt_tokens": 312,
  "completion_tokens": 18,
  "usage": {
    "prompt_tokens": 312,
    "completion_tokens": 18,
    "total_tokens": 330,
    "image_tokens": 290
  }
}
```

走 VLM 回退时 `confidence` 为 `null`，否则是 OCR 引擎报告的值，仅供参考。`language` 会原样返回你给的提示。

## 范例

<Tabs items={["curl", "Python", "JavaScript"]}>
<Tab value="curl">

```bash
curl http://localhost:8000/v1/images/generations \
  -H "Content-Type: application/json" \
  -d '{"model": "Z-Image-Turbo-MLX-4bit", "prompt": "a red bicycle in the rain", "size": "1024x1024", "seed": 7}' \
  | python3 -c "import sys,json,base64; open('out.png','wb').write(base64.b64decode(json.load(sys.stdin)['data'][0]['b64_json']))"

curl http://localhost:8000/v1/images/edits \
  -F image=@out.png \
  -F prompt="make it night" \
  -F denoise_strength=0.6

curl http://localhost:8000/v1/ocr -F file=@receipt.png -F task=text
```

</Tab>
<Tab value="Python">

```python
import base64
from openai import OpenAI

client = OpenAI(base_url="http://localhost:8000/v1", api_key="not-needed")

img = client.images.generate(
    model="Z-Image-Turbo-MLX-4bit",
    prompt="a red bicycle in the rain",
    size="1024x1024",
    response_format="b64_json",
)
with open("out.png", "wb") as f:
    f.write(base64.b64decode(img.data[0].b64_json))

with open("out.png", "rb") as f:
    edited = client.images.edit(
        model="Z-Image-Turbo-MLX-4bit",
        image=f,
        prompt="make it night",
        response_format="b64_json",
    )
```

</Tab>

import OpenAI from "openai";

const client = new OpenAI({ baseURL: "http://localhost:8000/v1", apiKey: "not-needed" });

## 错误

错误使用 OpenAI 的格式 `{"error": {"message", "type", "param", "code"}}`。

| 状态码 | 情况 |
| --- | --- |
| `400` | `prompt` 或 `image` 为空白、`size` 无法解析或不是介于 64 到 2048 的 64 倍数、`response_format` 不合法、base64 无效、OCR 上传的不是图片。 |
| `404` | 没有符合 `model` 的图像生成模型，或该模型属于其他模态。 |
| `413` | 图片上传超过 25 MB（OCR：超过 10 MB）。 |
| `501` | 仅图像生成：已加载的图像模型使用管线无法运行的布局（扁平的 Lance/Wan 类 checkpoint）。编辑与变体遇到同样情况会返回 `500`。 |
| `503` | OCR：没有加载 OCR 或视觉语言模型。 |
| `507` | GPU 内存不足。 |
| `500` | 生成、编辑、变体或 OCR 失败。 |
