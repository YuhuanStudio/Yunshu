title: OCR
description: POST /v1/ocr 会用 OCR 模型把上传的图片转成文本；没有加载 OCR 模型时，改用任何已加载的视觉语言模型。
---

`POST /v1/ocr` 是 Yunshu 自己的路由，不属于 OpenAI API。它接收一张上传的图片，返回从中读出的文本。`yunshu ocr` 与主控台的“图片识别”对话框使用的是同一条路由。

<Endpoint method="POST" path="/v1/ocr" />

<Callout type="info">
只有设置了 `YUNSHU_AUTH_TOKEN` 才会强制验证。使用 API 密钥时，该密钥需要推理权限，并且能访问最终实际服务此请求的模型。
</Callout>

## 请求

`multipart/form-data`。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | file | 是 | 图片，最大 10 MB。上传内容会以 Pillow 验证，不是图片时返回 `400`。可读取 PNG、JPEG、WebP、TIFF、BMP。 |
| `model` | string | 否 | OCR 模型或视觉语言模型的 id。留空表示使用第一个已加载的 OCR 模型。 |
| `task` | string | 否 | `text`（默认）、`formula` 或 `table`，决定识别提示词（`Text Recognition:`、`Formula Recognition:`、`Table Recognition:`）；未知的值视同 `text`。 |
| `language` | string | 否 | 引导输出语言的提示（“Respond in ...”）。不会做语言检测。 |

## 如何选择模型

1. 优先使用已加载的 OCR 类模型：`model` 指定的那一个，`model` 留空时用第一个已加载的。若 `model` 指向已注册但尚未加载的 OCR 模型，模型管理器会尝试加载它。
2. 否则退而使用已加载的视觉语言模型：`model` 若是已加载的 VLM 就用它，不然用任何一个已加载的 VLM。图片会搭配任务提示词与“Extract all text from this image verbatim”发送，采用贪婪解码（`temperature` 为 0），最多生成 2048 个新 token。OCR 引擎路径上限为 4096。
3. 两者都没有时，服务器返回 `503`。

密钥的模型范围会针对实际解析出的模型再检查一次，所以受模型范围限制的密钥不能靠留空 `model` 绕到其他模型。

## 响应

```json
{
  "text": "Invoice 2026-001\nTotal: 120.00",
  "model": "mlx-community/GLM-OCR-bf16",
  "confidence": null,
  "language": null,
  "task": "text",
  "prompt_tokens": 312,
  "completion_tokens": 18,
  "usage": {
    "prompt_tokens": 312,
    "completion_tokens": 18,
    "total_tokens": 330,
    "image_tokens": 290
  }
}
```

| 字段 | 说明 |
| --- | --- |
| `text` | 提取出的文本。模型什么都没读到时可能是空字符串。 |
| `model` | 实际服务此请求的模型 id。 |
| `confidence` | 一律为 `null`：两条路径都不生成置信度分数，Yunshu 也不会捏造。 |
| `language` | 走 VLM 回退时是你给的 `language` 提示；走 OCR 引擎路径时为 `null`。不做检测。 |
| `task` | 原样返回请求的 `task`。 |
| `prompt_tokens`、`completion_tokens`、`usage` | token 数量。`usage.image_tokens` 是图片占的部分；走 VLM 回退且引擎未上报时，会按图片尺寸与视觉配置估算。 |

响应不含文本框或位置，只有文本。

## 示例

<Tabs items={["curl", "Python", "CLI"]}>
<Tab value="curl">

```bash
curl http://localhost:8000/v1/ocr \
  -F file=@receipt.png \
  -F task=text \
  -F language="English"
```

</Tab>
<Tab value="Python">

```python
import requests

with open("receipt.png", "rb") as f:
    r = requests.post(
        "http://localhost:8000/v1/ocr",
        files={"file": ("receipt.png", f, "image/png")},
        data={"model": "", "task": "text"},
        timeout=180,
    )
r.raise_for_status()
print(r.json()["text"])
```

</Tab>
<Tab value="CLI">

```bash
yunshu ocr page.png
```

</Tab>
</Tabs>

## 取消

请求会登记到请求追踪器，客户端断开连接或调用 `POST /v1/cancel`（见[扩展](/docs/api/extensions)）时会被取消。在 OCR 引擎路径上，生成调用本身会跑到 token 上限；处理函数会立即返回，结果则被丢弃。在 VLM 回退路径上，生成会在解码步骤之间停止。

## 错误

| 状态码 | 情况 |
| --- | --- |
| `400` | 上传的文件不是服务器能读取的图片。 |
| `401`、`403` | 缺少或无效的凭证，或该密钥不可推理、不可使用实际解析出的模型。 |
| `413` | 图片超过 10 MB。 |
| `503` | 没有加载 OCR 模型，也没有加载视觉语言模型。 |
| `507` | GPU 内存不足。 |
| `500` | 提取失败；原因在服务器日志中。 |
