## Use YunUI

For requests to build with YunUI, read `.claude/skills/yunui/SKILL.md` before writing UI.
Import and compose the installed components; use the catalogue and packaged
recipes identified in `.yunui/context.json`. Run `yunui doctor --strict`
and repair setup failures instead of approximating the design with new controls.
User instructions and this project's existing constraints take precedence.
